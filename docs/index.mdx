Cookie is a private, AI-assisted email application built as three cooperating runtime codebases, with a fourth repository documenting the system:

- **[Cookie-Web](/components/cookie-web)** — the Vue 3 browser app and its Auth0-protected Vercel API functions. The production app runs at [mail.infinitywave.online](https://mail.infinitywave.online).
- **[Cookie-Worker](/components/cookie-worker)** — independently deployable Cloudflare Workers that ingest inbound mail, run overnight AI enrichment, and flush scheduled sends.
- **[Cookie-iOS](/components/cookie-ios)** — a native SwiftUI client ("Cards & Stacks" design) that talks to the same Cookie-Web API as the browser app.
- **[Cookie-Docs](/components/cookie-docs)** — this Blume/MDX site, deployed to GitHub Pages; it documents the system but owns no runtime or user data.

:::note
This site documents the system as a whole. Each component also carries its own `README.md` (and, for Cookie-Worker, a `RUNBOOK.md`) in its repository — those are the authoritative source for exact commands and configuration values.
:::

## At a glance

| | |
| --- | --- |
| Product | Private, single-user AI email client |
| Frontend | Vue 3 (web), SwiftUI (iOS) |
| API | Vercel Functions (Node, Auth0-protected) |
| Background processing | Cloudflare Workers |
| Database | Supabase Postgres + pgvector, shared by Web and Worker |
| AI | OpenAI Responses API, Embeddings API (`text-embedding-3-small`) |
| Outbound email | Resend |
| Authentication | Auth0 |
