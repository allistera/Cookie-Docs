Cookie is a private, AI-assisted productivity suite. Four repositories make up the mail application, while a fifth hosts a separate data-collection API:

- **[Cookie-Web](/components/cookie-web)** — the Vue 3 browser app, legacy Vercel send endpoint, and owner of the shared mail-app schema. The production app runs at [mail.infinitywave.online](https://mail.infinitywave.online).
- **[Cookie-Worker](/components/cookie-worker)** — ten browser-facing APIs plus three background Cloudflare Workers for inbound mail, AI enrichment, and scheduled sends.
- **[Cookie-iOS](/components/cookie-ios)** — a native SwiftUI client ("Cards & Stacks" design) that talks to the same Cookie-Web API as the browser app.
- **[Cookie-Docs](/components/cookie-docs)** — this Blume/MDX site, deployed to GitHub Pages; it documents the system but owns no runtime or user data.
- **[Cookie-Agents](/components/cookie-agents)** — a separate Render-hosted FastAPI service that collects Gmail and live Todoist data into its own PostgreSQL database. It is not on the Cookie mail application's request path and does not share its Supabase schema.

:::note
This site documents the system as a whole. Each component also carries its own `README.md` (and, for Cookie-Worker, a `RUNBOOK.md`) in its repository — those are the authoritative source for exact commands and configuration values.
:::

For a visual map of how the pieces fit together, open the interactive [system overview diagram](/Cookie-Docs/diagrams/system-overview.html) — pan, zoom, guided views, and export.

## At a glance

| | |
| --- | --- |
| Product | Private, single-user AI email client |
| Frontend | Vue 3 (web), SwiftUI (iOS) |
| Mail application API | Cloudflare Workers (Auth0-protected), plus the legacy Vercel send endpoint |
| Background processing | Cloudflare Workers |
| Database | Supabase Postgres, shared by Web and Worker |
| Search | Meilisearch Cloud hybrid/federated search (`messages`, `documents`, and `tasks` indexes) |
| AI | OpenAI Responses API |
| Outbound email | Resend |
| Authentication | Auth0 |
