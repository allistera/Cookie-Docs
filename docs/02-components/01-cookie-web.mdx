Cookie-Web is Cookie's browser client and the owner of the [shared Supabase schema](/data-model). The SPA is deployed at [mail.infinitywave.online](https://mail.infinitywave.online). Its browser-facing APIs have moved almost entirely to the `cookie-web-*` Cloudflare Workers in Cookie-Worker; this repository retains `api/send.js` as a compatibility endpoint used by the current web and iOS clients.

## Technology

| Area | Technology |
| --- | --- |
| UI | Vue 3, Pinia, Vue Router, Vite |
| Hosting | Vercel static SPA |
| API | Ten Cloudflare Workers, plus legacy Vercel `/api/send` |
| Authentication | Auth0 |
| Database | Supabase Postgres |
| Realtime | Supabase Realtime broadcast |
| Search | Meilisearch hybrid/federated search |
| AI | OpenAI Responses API |
| Outbound email | Resend |

## Layout

<FileTree>

  - stores/ — mail, documents, projects, tasks, and federated search state
  - lib/ — Worker origins and framework-independent helpers

- e2e/ — Playwright end-to-end tests and Worker fixtures

</FileTree>

## Frontend routes

Every route requires Auth0 authentication, enforced by both the `App.vue` render gate and `router.beforeEach`.

| Path | View | Purpose |
| --- | --- | --- |
| `/` | `AIInboxView` | AI Today: built-in tasks due/overdue, email triage, and personalised news |
| `/inbox` | `TraditionalInboxView` | Classic inbox, labels, folders, search entry, and message actions |
| `/calendar` | `CalendarView` | Calendars, events, recurrence, ICS subscriptions, and natural-language event creation |
| `/scheduled` | `ScheduledSendsView` | Pending Send Later messages |
| `/documents/:id?` | `DocumentsView` | Notes/documents editor with folders, templates, tags, tables, and export |
| `/search` | `SearchResultsView` | Unified mail, documents, and tasks results |
| `/tasks` | `TasksView` | Today/Inbox/project task lists, nested projects, detail panel, and subtasks |
| `/settings/:section?` | `SettingsView` | Account, labels/rules, personalisation, calendars, and integration settings |

## API ownership

The production SPA calls Worker custom domains declared in `src/lib/apiWorkers.js`. With the exceptions noted below, each Worker uses the same Auth0 access token and user-binding rule: verified issuer plus immutable `sub` maps to `users.auth0_sub`; email claims never select a mailbox.

| Origin / Worker | Routes used by the web app |
| --- | --- |
| `emails-api` / `cookie-web-emails` | `GET /emails`, `GET /emails/state` |
| `messages-api` / `cookie-web-messages` | message read/state/unsubscribe, bodies, attachments, contacts |
| `labels-api` / `cookie-web-labels` | label and label-rule CRUD |
| `ai-api` / `cookie-web-ai` | `POST /compose`, `POST /summarize` |
| `calendar-api` / `cookie-web-calendar` | calendar/event CRUD, subscriptions, sync, and AI interpretation |
| `search-api` / `cookie-web-search` | `GET /search` for mail or federated scopes; `POST /ask` for mailbox Q&A |
| `tasks-api` / `cookie-web-tasks` | AI Today, task projects/items/subtasks, documents, preferences, and refresh |
| `notifications-api` / `cookie-web-notifications` | `POST /notification-event` claim/ack |
| `receipts-api` / `cookie-web-receipts` | authenticated status reads and the unauthenticated tracking pixel |
| `send-api` / `cookie-web-send` | deployed Cloudflare send/schedule API; scheduled flusher calls `/send/flush` over a service binding |
| Vercel `mail.infinitywave.online` | current web-client compatibility calls to `/api/send` for send, schedule, cancel, and follow-up reminders |

:::note
The Cloudflare routes use clean paths instead of the former Vercel `?resource=` multiplexing. Cookie-Web's remaining `/api/send` file is a compatibility path, not evidence that the other APIs still run on Vercel.
:::

## Tasks and unified search

Cookie's Tasks app stores user-authored work separately from the overnight enricher's email-derived `tasks` rows. It supports a static Inbox, Today (including overdue work), nested projects, editable task details, completion, reassignment, due dates, and subtasks through the task panel.

The header search is available across applications and routes to `/search`. `cookie-web-search` federates Meilisearch results from the `messages`, `documents`, and `tasks` indexes, then hydrates owned rows from Postgres. Scope tabs can restrict results to mail, documents, or tasks. Mailbox Q&A remains mail-only.

## Local development

```sh
npm install
npm run dev
```

Without `DATABASE_URL`, local API middleware and Playwright routes use fixture data. Routine validation is:

```sh
npm run format:check
npm run lint
npm run test:unit -- --run
npm run build
npm run test:e2e
```

## Configuration highlights

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | Supabase Postgres connection for the Vercel send route and migrations |
| `RESEND_API_KEY` / `EMAIL_FROM` | Outbound delivery through the legacy Vercel compatibility path |
| `SCHEDULED_SEND_FLUSH_TOKEN` | Protects Vercel's legacy flush path; the Cloudflare send Worker uses the matching flusher secret for `/send/flush` |
| `PUBLIC_APP_URL` | Public origin used when constructing read-receipt pixels |
| `VITE_AUTH0_DOMAIN` / `VITE_AUTH0_CLIENT_ID` / `VITE_AUTH0_AUDIENCE` | Browser Auth0 configuration |
| `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` | Content-free Realtime inbox pings |

The Worker API origins are public constants in `src/lib/apiWorkers.js`, not environment secrets.

Pushes to `main` run format, lint, unit, build, and Chromium end-to-end jobs. Vercel deploys the SPA automatically; migration changes also trigger the `Migrate Database` workflow.
